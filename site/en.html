About this software

When you use an IME, entering an email address or other Latin text can leave you with a keyboard layout you did not intend to use.

IME Layout Router is a Windows tray utility that watches the input state and switches to your chosen keyboard layout when direct input is active.

あ / 中文 / 한글 → your IME   /   A / Latin input → your preferred layout

Chinese and Korean support is planned for V2. Behavior varies by application and input field. Tested configurations will be listed when each edition is released.

Getting started

  1. Add your preferred IME and target keyboard layout in Windows.
  2. Start the application and select the source IME and target layout.
  3. Save your settings. The application runs in the notification area.

Before upgrading, exit the running older version, then install the new one.

V1 and V2 are intended to be used one at a time. Settings migration instructions will accompany each release.

Compatibility notes

  • This utility switches keyboard layouts. It does not replace your IME.
  • Some applications or IMEs do not expose the input state the utility needs.
  • The first keystroke immediately after moving to another field may arrive before the layout has switched.

If something does not work, include your Windows version, IME, application and target layout in your report. You do not need to share what you typed or any passwords.
