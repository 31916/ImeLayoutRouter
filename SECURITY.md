# Security and public reports

This is a public repository: issues, pull requests, comments and committed files
can be read by anyone. Use dummy text when reproducing an input problem.

Do not attach passwords, API tokens, cookies, private keys, personal documents,
browser session exports, or unredacted desktop screenshots. Review diagnostic
reports before sharing them, including application paths and account names.
The application's diagnostic mode records input-state metadata, not typed text;
this is not a guarantee that every file or screenshot you attach is anonymous.

For a security vulnerability, use the [private vulnerability report form](https://github.com/31916/ImeLayoutRouter/security/advisories/new).
Do not put exploitable vulnerability details or credentials in a
public issue. An exposed credential must be revoked at its provider; deleting a
file or adding it to `.gitignore` does not remove copies from Git history.

## 日本語

このリポジトリのIssue・PR・コメント・コミットは公開されます。入力の不具合は
ダミーの文章で再現してください。パスワード・APIキー・Cookie・秘密鍵・個人の
文書・ブラウザーのセッション情報・未加工のデスクトップ画像は添付しないでください。
診断ファイルも、アプリのパスやアカウント名などを確認してから共有してください。

脆弱性は [非公開の報告フォーム](https://github.com/31916/ImeLayoutRouter/security/advisories/new)
から報告してください。公開Issueに認証情報や悪用可能な詳細を書かないでください。
漏えいした認証情報は発行元で失効させる必要があります。ファイルを削除したり
`.gitignore` に追加したりしても、Gitの過去の履歴からは消えません。
