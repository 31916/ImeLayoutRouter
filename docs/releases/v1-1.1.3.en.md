# Ver1.1.3 — Japanese essentials

Chrome and Edge can expose a numeric or decimal web input as an ordinary text field while the IME shows direct input. Previous versions could leave the source IME active instead of selecting the configured target layout.

Standard number and email fields use the built-in Windows detector. For numeric or decimal text inputs and simple ASCII-digit patterns, select the optional Chrome/Edge files in the installer, load the extension, and enable the site. The extension does not read entered digits or authentication codes. A restriction implemented only in a site's JavaScript cannot be classified from the field's attributes. [Setup and scope](https://github.com/31916/ImeLayoutRouter/blob/V2/browser-extension/README.md#english)
