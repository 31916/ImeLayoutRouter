# Ver1.1.2 — Japanese essentials

Updated October 20, 2026 (Japan time) | [日本語](v1-1.1.2.md) | [Download page](https://31916.ch/IMELayoutRouter/en.html)

The lightweight edition selects an existing Windows input layout for Japanese IME direct input. Settings and the installer are Japanese-only. The original application icon is retained.

## Changes

- Fix an unexpected process exit when an exception occurs while reading an application's input-field metadata. A failed read is treated as unknown and monitoring continues. Normal classification resumes when valid metadata is available again.
- Repair the startup registration when updating a prototype installed in its original default location. Migration requires an existing enabled registration; it preserves Windows startup approval and another edition's registration.
- Remove unused internal constants and routine console output, and limit packaged documentation to user-facing files.

Settings locations, application ID and installation directory are unchanged. The app does not edit key mappings or layout definitions, or install input methods. See the [base specification and instructions](v1-1.1.0.en.md).

## Cause and verification

A Windows crash record from an affected V2 installation showed an unhandled `NullReferenceException` from `IAccessible.get_accFocus` in the field-monitoring thread. Both editions use the repaired accessibility-reading code. The record does not identify which application's accessibility provider triggered the exception.

The same exception path was reproduced against the previous implementation. After the repair, all 42 regression scenarios pass for each edition, including failed focus, state, metadata and nested-field reads, followed by recovery on a valid observation. Release builds of both editions complete without warnings or errors. No reading, saving or sending of typed text was added.

These checks do not establish long-running stability in every application. Physical-key input in the reported browser email field and previously outstanding Microsoft Japanese IME compatibility checks are not counted as completed. See the [previous validation record](https://github.com/31916/ImeLayoutRouter/blob/V2/docs/browser-field-fix-2026-09-26.md).
