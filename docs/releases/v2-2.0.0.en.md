# V2 2.0.0 — Full edition

Released September 20, 2026 (Japan time) | [日本語](v2-2.0.0.md) | [Download page](https://31916.ch/IMELayoutRouter/en.html)

The main edition provides controls for multiple IMEs and different applications. It can select Japanese, Chinese and Korean IMEs; its settings and installer support Japanese and English.

"Layout switching" means selecting an existing input layout enabled in Windows.
When direct input is detected for a source IME, the router asks the application
receiving input to use the configured target layout. If accepted, the same physical
keys can produce different characters or punctuation. The app does not create or
edit key mappings/layout definitions, or install additional IMEs/layouts.
V2's manual switching also selects existing input layouts.

**Actual typing in browser email fields and real-machine behavior with Microsoft Japanese, Chinese and Korean IMEs remain unverified.** Implemented selection/routing support does not establish compatibility in every environment.

## Features

- **Multiple IMEs:** select one source or cover all enabled Japanese, Chinese and Korean source languages.
- **Application rules:** enable or disable automatic routing by executable path, including an allowlist configuration.
- **Status:** view the observed layout/mode and routing reason in the tray. Pending requests are distinguished from confirmed changes.
- **Manual controls:** pause/resume, switch to the target, or return to a previously observed layout in the same window.
- **Optional shortcuts:** Ctrl+Alt+F8 pauses/resumes, F9 selects the target and F10 restores the previous layout. Shortcuts are disabled by default.
- **Guided settings and typing check:** try settings inside the settings window before saving, without enabling global shortcuts.
- **Diagnostics:** save a 30-second input-state log. The feature does not intentionally read or record entered text, passwords, keystrokes, window titles or URLs.

## Fixes

Includes the repairs shared with [V1](v1-1.1.0.en.md): persistent direct-input detection, field metadata fallback, retries and rejection of stale focus information. Startup disabling and uninstall remove only this edition's own registration. The original application icon is retained.

## Install and upgrade

1. Make sure your source IME and target layout are enabled in Windows.
2. Exit any older running copy through its tray menu, then run the installer.
3. Choose the source and target; configure application rules if needed.
4. Try the typing check and save. Enable startup and shortcuts only if wanted.

Use one edition at a time. V2 saves settings to `%LOCALAPPDATA%\ImeLayoutRouter\settings-v2.json`. It imports the old `settings.json` while preserving that original file. Settings are not shared with V1. Back up settings before downgrading.

## Tested environment and limitations

- Native Windows test controls passed Japanese composition, layout switching and punctuation with Windows 11 build 26200, Google Japanese Input 3.34.6260.0 and a Swiss German keyboard.
- Test fixtures passed application exclusion, pause/resume, manual switching/restoration and Windows hotkey delivery. Japanese/English settings checks and 30 regression scenarios passed.
- The final installer passed installation, same-version reinstallation, uninstall and preservation of settings and another edition's startup registration.
- Chrome/Edge/Firefox input fields, Microsoft Japanese, Pinyin, Bopomofo and Korean IMEs, startup at sign-in, the complete diagnostic-save UI flow and every historical upgrade path remain unverified.
- The first key after moving between fields can arrive before switching completes. Some applications and IMEs do not expose sufficient state or metadata.
- Sources are matched by Windows language ID; individual IMEs sharing the same ID cannot be reliably distinguished.
- Moving to an ordinary field does not automatically select the source IME. Manually switching from the target layout back to the IME requests native input restoration.
