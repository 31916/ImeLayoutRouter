# Ver2.0.1 — Full edition

Released September 26, 2026 (Japan time) | [日本語](v2-2.0.1.md) | [Download page](https://31916.ch/IMELayoutRouter/en.html)

The full edition supports existing Japanese, Chinese and Korean source IMEs, application rules, routing status and manual controls. Settings and the installer support Japanese and English. The original application icon is retained.

## Changes

- Request browser field metadata before rejecting an initially unfocused or read-only accessibility placeholder. This lets the browser expose its actual focused input before classification.
- Preserve focused-field validation, avoid using a parent's input type, and reject cyclic focus chains.
- Use the single version label **Ver2.0.1** on the download page.

Existing features and settings locations are unchanged. The app does not edit key mappings or layout definitions, or install input methods. See the [base specification and instructions](v2-2.0.0.en.md).

## Verification

All 35 regression scenarios pass. Both editions pass build and noninteractive settings checks, including Japanese/English full-edition settings. Windows CI checks the distributed installers' install/reinstall/uninstall lifecycle, settings preservation, original icon and version metadata.

**Physical-key input in the reported browser email field remains unverified.** The detection-protocol defect is repaired, but resolution of that reported symptom is not yet confirmed on the actual machine. Previously unverified Microsoft Japanese, Chinese and Korean IME compatibility remains outstanding. See the [validation record](../browser-field-fix-2026-09-26.md).
