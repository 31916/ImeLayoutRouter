# Ver2.0.3 — 多機能版

Chrome・Edgeの数字欄で、IMEが「A」になっても設定したWindows入力レイアウトに切り替わらない問題に対応しました。旧版では、`inputmode="numeric"` や `inputmode="decimal"` の付いたテキスト欄を通常の日本語欄と区別できませんでした。

通常の数値欄とメール欄はアプリ単体で判定します。数字入力モードや数字だけの単純なパターンを持つ欄では、インストーラーで任意のChrome・Edge用ファイルを選び、拡張を読み込んで対象サイトを有効にしてください。入力値・認証コードは読みません。サイト独自のJavaScriptだけで制限する欄は判別できません。[設定手順](https://github.com/31916/ImeLayoutRouter/blob/V2/browser-extension/README.md#日本語)

更新前に起動中の旧版を終了してください。[ダウンロードページ](https://31916.ch/IMELayoutRouter/)
