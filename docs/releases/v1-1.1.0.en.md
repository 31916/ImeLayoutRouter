# V1 1.1.0 — Japanese essentials

Released September 20, 2026 (Japan time) | [日本語](v1-1.1.0.md) | [Download page](https://31916.ch/IMELayoutRouter/en.html)

V1 provides the essential controls for using a Japanese IME alongside your preferred keyboard layout. Its settings and installer are in Japanese.

**Actual typing in browser email fields and real-machine behavior with Microsoft Japanese IME remain unverified.** The repairs below are implemented; compatibility with every application has not been established.

## Fixes

- Check for routing when direct/Latin input is already active at startup.
- Use email, URL, telephone, number and password field metadata to detect field-forced direct input, including cases where the IME still reports native input.
- Improve retries when a layout request does not take effect and reject stale field information after focus changes.
- Remove only this edition's own startup registration when disabling startup or uninstalling.

## Included features

- Japanese source IME and target keyboard layout selection.
- Automatic routing, tray operation and an optional Windows sign-in startup setting.
- A simple Japanese settings window and the original application icon.

Application rules, status displays, shortcuts, a typing check and diagnostics are included in [V2](v2-2.0.0.en.md). V1 excludes those advanced features. Both editions include the same .NET runtime, so their download sizes are similar.

## Install and upgrade

1. Make sure your Japanese IME and target layout are enabled in Windows.
2. Exit any older running copy through its tray menu, then run the installer.
3. Choose your source IME and target layout and save. Enable startup if needed.

Use one edition at a time. V1 saves settings to `%LOCALAPPDATA%\ImeLayoutRouter\settings-v1.json`. It can load the old `settings.json` without overwriting that file. V1 and V2 store their settings separately.

## Tested environment and limitations

- Native Windows test controls passed Japanese composition, layout switching and punctuation with Windows 11 build 26200, Google Japanese Input 3.34.6260.0 and a Swiss German keyboard.
- The final installer passed installation, same-version reinstallation, uninstall, preservation of existing settings and preservation of another edition's startup registration.
- Chrome/Edge/Firefox input fields, Microsoft Japanese IME, startup at sign-in and every historical upgrade path remain unverified.
- A first key immediately after changing fields can arrive before routing completes. Applications that expose neither the necessary input state nor field metadata cannot be classified reliably.
- Moving to an ordinary field does not automatically select the source IME. Manually switching from the target layout back to the Japanese IME requests native input restoration.

See the [acceptance record](../acceptance-2026-09-20.md) and [README](../../README.md). The router does not collect entered text or passwords.
