# Ver2.0.1 — 多機能メイン版

リリース日：2026年9月26日（日本時間）｜ [English](v2-2.0.1.en.md) ｜ [配布ページ](https://31916.ch/IMELayoutRouter/)

Windowsで有効な日本語・中国語・韓国語IMEを対象に、直接入力時の既存入力レイアウトへの切替、アプリ別ルール、状態表示、手動切替などを備えた版です。設定画面・インストーラーは日本語と英語に対応し、元のアプリアイコンを継続使用しています。

## 今回の修正

- ブラウザーが入力欄の情報を準備する前に検出を打ち切ってしまう処理を修正しました。フォーカスをたどる際に情報の取得を要求し、その後に入力欄の状態を判定します。
- 親要素の種類を入力欄の種類として誤用しない判定を維持し、循環するフォーカス情報も対象外にします。
- ダウンロードページのバージョン表記を「Ver2.0.1」に統一しました。

従来の機能・設定の保存先は変わりません。キー割り当てや配列定義の編集、入力方式の追加は行いません。[基本仕様・使い方](v2-2.0.0.md)も参照してください。

## 確認状況

35件の回帰テスト、両版のビルド、日本語・英語の設定画面の検査を通過しています。配布ファイルはWindows CIでインストール・再インストール・アンインストール、設定保持、元のアイコンとバージョン情報を検査しています。

**報告されたブラウザーのメール欄での実際のキー入力は未確認です。** 検出処理の不備は修正しましたが、報告された現象の解消を実機で確認したものではありません。Microsoft日本語・中国語・韓国語IMEなど、以前から残っている互換性確認も未完了です。[検証記録](../browser-field-fix-2026-09-26.md)を参照してください。
