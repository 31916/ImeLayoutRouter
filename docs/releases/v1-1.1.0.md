# V1 1.1.0 — 日本語簡易版

リリース日：2026年9月20日（日本時間）｜ [English](v1-1.1.0.en.md) ｜ [配布ページ](https://31916.ch/IMELayOutRouter/)

日本語IMEと好みのキーボード配列を使い分けるための、機能を絞った版です。
設定画面とインストーラーは日本語です。

**ブラウザーのメール欄などでの実入力と、Microsoft日本語IMEの実機動作は未確認です。**
以下の修正は実装済みですが、すべてのアプリでの動作確認が完了したものではありません。

## 修正内容

- IMEが最初から「A」の状態でも、指定した配列への切替を確認するようにしました。
- メール・URL・電話番号・数値・パスワード欄の情報を使い、IMEが日本語入力中と報告していても、入力欄が直接入力を求める場合を判定する処理を追加しました。
- 入力欄を移ったときの古い判定による誤切替を抑え、切替要求が反映されなかった場合の再試行を改善しました。
- 自動起動の解除・アンインストール時に、その版自身の起動設定だけを削除するようにしました。

## V1に含まれる機能

- 日本語IMEと切替先のキーボード配列の選択。
- 入力状態に応じた自動切替、通知領域への常駐、Windowsサインイン時の自動起動設定。
- 日本語の簡易設定画面。作成済みのオリジナルアイコンを使用。

アプリ別ルール、状態表示、ショートカット、入力確認欄、診断ログは
[V2](v2-2.0.0.md)に含まれます。V1はこれらの高度な機能を省いています。
両版とも.NETを同梱するため、ダウンロード容量に大きな差はありません。

## 導入・更新

1. 使用する日本語IMEと切替先の配列がWindowsで有効になっていることを確認します。
2. 起動中の旧版を通知領域のメニューから終了し、インストーラーを実行します。
3. 設定画面でIMEと配列を選び、保存します。自動起動は必要に応じて有効にします。

V1とV2は、どちらか一方を起動して使います。V1の設定は
`%LOCALAPPDATA%\ImeLayoutRouter\settings-v1.json` に保存します。
旧版の `settings.json` があれば読み込み、新しい設定を保存しても元のファイルを残します。
V2と同じ設定ファイルを共有するわけではありません。

## 動作確認と制限

- Windows 11（ビルド26200）、Google日本語入力 3.34.6260.0、スイス・ドイツ語配列の検証用Windows入力画面で、日本語入力・配列切替・記号入力を確認しました。
- 配布する最終インストーラーで、インストール・同じ版の再インストール・アンインストール、既存設定の保持、別の版の自動起動設定の保持を確認しました。
- Chrome・Edge・Firefoxの各入力欄、Microsoft日本語IME、サインイン時の自動起動、すべての旧版からの更新経路は未確認です。
- 入力欄を移った直後の最初のキーは、配列の切替に間に合わないことがあります。アプリが必要な入力状態や欄の情報を公開していない場合、切替を判定できません。
- 通常の入力欄に移るだけでは、日本語IMEへ自動で戻りません。切替先から日本語IMEへ手動で戻したときに、日本語入力への復帰を要求します。

詳しい検証記録は[受入確認の記録](../acceptance-2026-09-20.md)、
仕組みと互換性の説明は[README](../../README.md)を参照してください。
入力した文章やパスワードを収集する機能はありません。
