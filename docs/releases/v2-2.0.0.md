# V2 2.0.0 — 多機能メイン版

リリース日：2026年9月20日（日本時間）｜ [English](v2-2.0.0.en.md) ｜ [配布ページ](https://31916.ch/IMELayoutRouter/)

複数のIMEやアプリごとの使い分けを想定したメイン版です。
日本語・中国語・韓国語IMEの選択に対応し、設定画面とインストーラーは日本語・英語で利用できます。

本書の「配列の切替」は、Windowsで有効な既存の入力レイアウトを選び直す動作です。
対象IMEで直接入力を検出すると、入力中のアプリに設定したレイアウトへの切替を要求します。
受理されると、同じ物理キーから入力される文字や記号が変わることがあります。
キーごとの割り当てや配列定義を作成・編集する機能、IMEやレイアウトを追加する機能はありません。
V2の手動切替も、既存の入力レイアウトを選ぶ操作です。

**ブラウザーのメール欄などでの実入力と、Microsoft日本語・中国語・韓国語IMEの実機動作は未確認です。**
選択・切替処理への対応と、実環境での互換性確認は区別しています。

## 追加機能

- **複数IMEへの対応**：個別の切替元、またはWindowsで有効な日本語・中国語・韓国語IMEをまとめて対象にできます。
- **アプリ別ルール・除外**：実行ファイルごとに自動切替の有効・無効を設定できます。指定したアプリだけを対象にする設定も可能です。
- **現在の状態表示**：通知領域で配列・入力状態・切替理由を確認できます。切替要求中と確認済みの状態を区別します。
- **手動操作**：自動切替の一時停止、切替先への移動、同じウィンドウで前に観測した配列への復帰に対応します。
- **ショートカット**：有効にすると、既定でCtrl+Alt+F8が一時停止／再開、F9が切替先、F10が元の配列への復帰です。初期状態では無効です。
- **設定ガイド・入力確認欄**：設定を保存する前に、設定画面内で切替を試せます。この試用ではグローバルショートカットを有効にしません。
- **診断ログ**：入力状態を30秒間記録できます。入力した文章・パスワード・キー操作・ウィンドウタイトル・URLを読み取ったり記録したりする目的の機能はありません。

## 修正内容

[V1](v1-1.1.0.md)と共通の修正を含みます。
初めから「A」の状態にある場合の判定、メールなどの入力欄の情報による判定、
切替の再試行、古い入力欄の情報による誤切替の抑制を改善しました。
自動起動の解除・アンインストールは、その版自身の登録だけを削除します。
作成済みのオリジナルアイコンを使用しています。

## 導入・更新

1. 使用するIMEと切替先の配列がWindowsで有効になっていることを確認します。
2. 起動中の旧版を通知領域のメニューから終了し、インストーラーを実行します。
3. 設定画面でIMEと配列を選び、必要に応じてアプリ別ルールなどを設定します。
4. 入力確認欄で試してから保存します。自動起動とショートカットは必要に応じて有効にします。

V1とV2は、どちらか一方を起動して使います。V2の設定は
`%LOCALAPPDATA%\ImeLayoutRouter\settings-v2.json` に保存します。
旧版の `settings.json` があれば読み込み、元のファイルを残します。
V1との設定共有は行いません。古い版へ戻す前には設定をバックアップしてください。

## 動作確認と制限

- Windows 11（ビルド26200）、Google日本語入力 3.34.6260.0、スイス・ドイツ語配列の検証用Windows入力画面で、日本語入力・配列切替・記号入力を確認しました。
- 検証用画面でアプリ除外、一時停止／再開、手動切替・復帰、Windowsのショートカット通知を確認しました。日本語・英語の設定画面と、30件の回帰テストも通過しています。
- 配布する最終インストーラーで、インストール・同じ版の再インストール・アンインストール、既存設定と別の版の自動起動設定の保持を確認しました。
- Chrome・Edge・Firefoxの各入力欄、Microsoft日本語・Pinyin・Bopomofo・韓国語IME、サインイン時の自動起動、診断保存画面の一連の操作、すべての旧版からの更新経路は未確認です。
- 入力欄を移った直後の最初のキーは、配列の切替に間に合わない場合があります。アプリやIMEが必要な情報を公開していない場合、判定できません。
- 切替元の照合はWindowsの言語ID単位です。同じ言語IDを共有するIMEを厳密には区別できません。
- 通常の入力欄に移るだけでは切替元IMEへ戻りません。切替先からIMEへ手動で戻したときに、ネイティブ入力への復帰を要求します。

詳しくは[受入確認の記録](../acceptance-2026-09-20.md)と[README](../../README.md)を参照してください。
