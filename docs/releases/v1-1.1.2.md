# Ver1.1.2 — 日本語簡易版

更新日：2026年10月20日（日本時間）｜ [English](v1-1.1.2.en.md) ｜ [配布ページ](https://31916.ch/IMELayoutRouter/)

日本語IMEの直接入力（A）に合わせ、Windowsで有効な指定の入力レイアウトへ切り替える簡易版です。設定画面・インストーラーは日本語で、元のアプリアイコンを継続使用しています。

## 今回の修正

- 一部アプリの入力欄情報を取得する際に例外が発生すると、IMELayoutRouterの常駐プロセスが終了する不具合を修正しました。取得に失敗した情報を「不明」として扱い、監視を継続します。正常な情報を取得できれば通常の判定に戻ります。
- 旧プロトタイプを既定の場所から更新した場合に、自動起動の登録先が旧版のまま残る問題を修正しました。既存の自動起動が有効な場合だけ移行し、Windows側で無効にした状態や他の版の登録を変更しません。
- 不要な内部定数・通常時のコンソール出力を整理し、同梱文書を利用者向けのものに絞りました。

設定の保存先・アプリID・インストール先は変わりません。キー割り当てや配列定義の編集、入力方式の追加は行いません。[基本仕様・使い方](v1-1.1.0.md)も参照してください。

## 原因と確認範囲

実際に終了したV2のWindows記録では、アクセシビリティのフォーカス情報取得（`IAccessible.get_accFocus`）で発生した`NullReferenceException`が監視スレッドから外へ伝わり、プロセスが終了していました。共通の取得処理を修正し、V1にも適用しています。どのアプリの情報提供処理が例外を引き起こしたかは、この記録だけでは特定できません。

旧実装で同じ例外経路を再現し、修正後は両版それぞれ42件の回帰テストが通過しました。両版のReleaseビルドも警告・エラーなしで完了しています。フォーカス・状態・メタデータ・入れ子の入力欄で情報取得が失敗した場合と、その後の正常な観測への復帰を確認しています。入力した文字を取得・保存・送信する処理は追加していません。

この検査は、利用中のすべてのアプリで長時間終了しないことを保証するものではありません。ブラウザーのメール欄での実際のキー入力、Microsoft日本語IMEなど、以前から残っている互換性確認も完了した扱いにはしていません。[前版の検証記録](https://github.com/31916/ImeLayoutRouter/blob/V2/docs/browser-field-fix-2026-09-26.md)を参照してください。
